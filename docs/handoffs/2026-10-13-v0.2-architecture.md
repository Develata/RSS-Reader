## 关键变更

### 已确认的决定

- 正式 Web：资料库在服务器上，登录后任何设备获得完整功能；服务器上的 CLI 共用这份资料库。
- 演示站：GitHub Pages，浏览器内存 SQLite + 同一套仓储代码，不保存，刷新即重置，网络禁用。
- 存储：所有平台一个 `library.sqlite3`；逐步从 sqlx 迁到 rusqlite（迁移期 0.39，删除 sqlx 后 0.40）；新基线吸收未发布的 0008 / 0009。
- 兼容性：不兼容旧进程、旧浏览器存储与降级；保留 v0.1.0–v0.1.23 本机资料库的单向导入。
- GUI 与 CLI 仍是两个程序（见 `cli-gui-distribution.md`）。
- 版本：`v0.2.0`。

### 产品边界的表述

“不做文章库同步”保持不变；新增“资料库”定义：每个资料库独立，资料库之间只交换配置。服务器端 Web 是多个入口访问同一资料库，不是同步。
