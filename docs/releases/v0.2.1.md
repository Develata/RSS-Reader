# RSS-Reader v0.2.1

2026-10-28 正式发布：[下载 Release](https://github.com/Develata/RSS-Reader/releases/tag/v0.2.1)。源码固定为 `dbfbf8965f4bdfa6463f33c50d5fbf6c2fcd15ee`，完整变更见 [v0.2.0...v0.2.1](https://github.com/Develata/RSS-Reader/compare/v0.2.0...v0.2.1)。

## 本版变化

- 调整阅读工作区工具栏与来源筛选，支持显式多选和手动归档。
- 目录展开到具体文章，箭头移至右侧；父级箭头 6px、分支箭头 5px，文章缩进 8px，保留至少 44px 的点击高度。大目录按可见窗口挂载文章行。
- 修复快速筛选、目录跳转与返回时过期结果覆盖当前页面的问题，保留切页期间已接受的文章写入和工作区偏好。
- 改善 Android 连续阅读的系统返回，使用应用持久数据目录。
- 修复 Windows 上 Web release 的 wasm-opt 优化异常。
- 整理设计文档与历史交接，区分当前待办、历史验证和已由新架构替代的事项。

## 升级与回退

桌面和服务器应关闭旧程序并备份资料库后再升级。正式 Windows v0.2.1 已使用 v0.2.0 单库夹具验证：5000 篇文章、5000 篇正文和原有文章标记保留。该夹具没有自定义设置行，不能从此项推定所有设置迁移均已验收。

本版增加手动归档字段，升级后的库不能直接由 v0.2.0 打开。需要回退时恢复升级前备份，不能只换回旧程序；恢复备份后不会保留升级后的新文章与已读、收藏、归档变更。未发布开发版 schema 0008/0009 不属于正式导入范围；从 v0.1.x 升级见[资料库升级说明](../testing/native-upgrade-verification.md)。

Android 暂无应用内完整资料库备份和回退流程。升级前可导出配置，但它不包含文章及已读、收藏状态；卸载会清除本地数据，不要用卸载重装来回退。首次启动检测到可迁移的旧目录时，会复制到应用持久目录、校验并保留旧目录；目标存在且没有完成标记等冲突会停止迁移，不覆盖原数据。真实旧 Android 数据搬迁仍未完成正式包验收。

## 安装与核验

- 14 个公开附件均与实际 CI 文件和 GitHub SHA256 相符，见[附件清单](../testing/evidence/2026-10-28-v0.2.1-release/public-assets.json)。下载适合平台的完整安装包或压缩包。
- Windows GUI 启动、单库升级和正常关闭通过；Windows / Linux CLI 均回报 `rssr 0.2.1`。Windows 程序未做 Authenticode 签名，macOS 应用未签名或公证。
- Android APK/AAB 为 0.2.1 / 201，验签通过，证书与 v0.2.0 一致。隔离 Android 16 模拟器（x86_64 镜像，ARM64 经 native bridge）完成正式 APK 覆盖安装、持久目录初始化及旧 schema 单库夹具对照。该夹具来自 Windows，且在初始化后的目录预置；这不代表真实旧 Android 数据搬迁或真机正式包升级已通过。
- 四平台 Web 服务包各 6 项检查、容器 9 项检查通过。服务程序与 `public/` 必须配套使用，见[部署说明](../deployment/web.md)。发布时 GHCR `v0.2.1`、源码 SHA 标签与 `latest` 的摘要相同；长期固定版本请使用版本标签或摘要。
- 此前 Windows 与一台 Android 的专项交互结果仍按其实际构建记录；本轮没有把完整交互在所有正式安装包上重跑。系统 IME、辅助技术、其他 Android 设备及 macOS/Linux GUI 完整交互仍有未覆盖项。

正式包身份、工作流重试、逐平台证据和覆盖限制见[发布交接](../handoffs/2026-10-28-v0.2.1-release.md)。解析性能与后台图片队列的后续测量保留在[维护清单](../maintenance-backlog.md)。
