# RSS-Reader v0.2.2

2026-11-02 正式发布：[下载 Release](https://github.com/Develata/RSS-Reader/releases/tag/v0.2.2)。源码固定为 `1138d286904d6aa1d1be2277879999037317a483`，完整变更见 [v0.2.1...v0.2.2](https://github.com/Develata/RSS-Reader/compare/v0.2.1...v0.2.2)。

## 本版变化

- 修复 Linux 桌面版“全部文章”页鼠标滚轮完全失效；减轻 Linux 下快速滚动的卡顿（深色背景光晕改为角落固定区域，并关闭 WebKitGTK 平滑滚动，慢速滚轮因此按格移动）。
- 内置主题收拢为“默认”与 Amethyst Glass 两套，每套都含完整的浅色与深色，由“外观”（浅色 / 深色 / 跟随系统）切换。Midnight Ledger 的配色成为默认主题的深色外观；Atlas Sidebar、Newsprint、Midnight Ledger 下线。
- Android 可通过系统文档选择器导入主题 CSS。
- 移除“列表密度”选项，统一使用默认间距。
- 订阅与设置页统一顶部导航和内容面板；目录入口位置、固定标题和跨页跳转顺序修正；主题预览与保存统一。
- 修复 Reader 切文后旧图片消息打开旧图片、标记写入乱序覆盖新状态，以及重读恢复后残留错误提示的问题；正文解析与后台图片队列增加上限。
- 内部为将来的原生界面做规则与 WebView 适配层拆分，界面仍为 Dioxus / WebView。

## 升级说明

- 本版没有资料库 schema 变化。升级前仍建议关闭旧程序并备份资料库。
- 已保存的主题 CSS 是快照，升级不会改写。已下线主题仍按保存的 CSS 显示，设置页会提示更换。原先使用 Midnight Ledger 的用户，建议改选“默认”并把“外观”设为深色后保存，才能得到新的背景（Linux 下更流畅）。
- 旧配置中的“紧凑”列表密度保留兼容但不再生效。
- Linux deb 的桌面菜单名原为 `RssrApp`。同一 Release 补充了打包修订 `RSS-Reader-linux-x86_64-0.2.2-1.deb`：程序与 0.2.2 完全相同，只修正菜单名与软件包说明；[apt 源](https://develata.me/apt-repo/)已发布该版本，`apt upgrade` 即可得到。详见[交接](../handoffs/2026-11-02-linux-desktop-entry-name.md)。

## 验证范围

- 发布源码的 CI、Docker、Pages 均通过；Release 工作流全部构建与发布 job 成功（macOS ARM64 构建首次因下载 Dioxus CLI 时 GitHub API 返回 403 失败，未改代码重跑后通过）。
- Linux 附件已下载核对：SHA256 与 GitHub 记录一致；deb 为 rssr-app / 0.2.2 / amd64；`rssr-cli --version` 输出 `rssr 0.2.2`；Web 服务包构建标识为 `git-1138d286…`。GHCR `v0.2.2`、源码 SHA 标签与 `latest` 指向同一摘要。
- 本版发布前没有在 Windows、Android、macOS 正式包上重跑完整交互；Linux 桌面的滚轮与卡顿修复只在一台 Debian 13 / GNOME Wayland / NVIDIA 机器上实测。Windows 未做 Authenticode 签名，macOS 未签名或公证。
