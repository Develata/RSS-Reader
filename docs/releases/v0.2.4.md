# RSS-Reader v0.2.4

[下载 Release](https://github.com/Develata/RSS-Reader/releases/tag/v0.2.4)。完整变更见 [v0.2.3...v0.2.4](https://github.com/Develata/RSS-Reader/compare/v0.2.3...v0.2.4)。

## 本版变化

- WebDAV 自动同步：设置页可以“记住并自动同步”一个 WebDAV 端点。程序启动（首轮自动刷新完成后）以及设置、订阅增删改、导入成功后，按上次同步的基准自动上传或下载配置包。两边都改过，或刚记住且两边内容不同时不自动处理，由你手动选择上传或下载。只同步订阅与设置，不同步文章、已读、收藏。规则见[使用说明](../user-guide.md)与[设计](../design/webdav-auto-sync.md)。
- WebDAV 填写方式：Endpoint 只填文件夹地址（形如 `https://example.com/dav/path/`），用户名、密码分两栏填写，任何字符都不必转义，密码框可切换显示。配置固定保存为该文件夹里的 `rss-reader.json`，去掉了 Remote Path 栏。
- macOS：恢复系统编辑与窗口快捷键（Cmd+C / V / X / Z / A、Shift+Cmd+Z、Cmd+Q / W / M / H），桌面端新增应用、编辑、窗口三个系统菜单。此前各版本里这些键在 macOS 上都不起作用。Windows、Linux 不变。
- 性能：文章列表、列表旁的归档计数和订阅页的未读 / 总数不再逐篇读取全部文章。25 万篇时默认首页列表约 35 → 3 ms，归档计数与订阅页摘要约 195–200 → 8 ms。
- 内部：适配 Rust 1.100 的构建产物目录变化（规则边界检查与 Windows 发布 UI 验收）。

## 升级说明

- 本版新增资料库迁移 0003：只加一个索引，不改数据，在新版首次打开资料库时建立（25 万篇在 Apple Silicon 上约 0.4 秒，库文件约增大 3%）。升级后的库不能再由 v0.2.3 及更早版本打开（提示“资料库由更新版本的程序创建”）；回退时必须恢复升级前备份，不能只换回旧程序。升级前请关闭旧程序并备份资料库。
- WebDAV 远端文件：v0.2.3 及更早版本默认上传到 Endpoint 下的 `config/rss-reader.json`，本版固定为 Endpoint 文件夹里的 `rss-reader.json`。要接着用旧文件，把 Endpoint 指向原来的 `config/` 文件夹即可。
- WebDAV 凭据：设置页 Endpoint 里写了用户名或密码（`https://用户名:密码@…`）会被拒绝，请改填“用户名”“密码”两栏。CLI 的 `--endpoint` 写法不变。
- 记住端点后，端点与凭据以明文保存在数据目录的 `remote-sync.json`（Linux、macOS 上仅所有者可读写；自托管 Web 保存在服务器数据目录，浏览器不保存凭据）。它不进入资料库、配置包或 `rssr-cli backup` 的备份；复制整个数据目录的备份会包含它，请按密码保管。“停用自动同步”删除该文件。
- 已知限制：
  - WebDAV 服务器不返回强 ETag 时，从读取远端到上传完成之间，另一台设备的上传可能被覆盖；返回强 ETag 的服务器会识别为冲突并交给你选择。
  - 同一数据目录不要同时运行两个记住了端点的程序（例如桌面端与服务器共用数据目录）。自托管 Web 的自动同步在服务进程启动时运行，不是打开页面时。
