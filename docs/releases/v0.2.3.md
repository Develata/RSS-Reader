# RSS-Reader v0.2.3

[下载 Release](https://github.com/Develata/RSS-Reader/releases/tag/v0.2.3)。完整变更见 [v0.2.2...v0.2.3](https://github.com/Develata/RSS-Reader/compare/v0.2.2...v0.2.3)。

## 本版变化

- macOS：应用包改为整包 ad-hoc 签名，从浏览器下载后不会再被判为“已损坏”。没有 Developer ID 签名与公证，首次打开若提示无法验证开发者，到“系统设置 → 隐私与安全性”选择“仍要打开”。菜单栏与程序坞名称由 `RssrApp` 改为 `RSS-Reader`。
- Linux：deb 的桌面菜单名改为 `RSS-Reader`，与 0.2.2-1 打包修订一致。
- CLI 可用 `cargo binstall --git https://github.com/Develata/RSS-Reader rssr-cli` 从 Release 附件安装。Windows 与 Linux 上这样装的 CLI 默认把数据放在可执行文件旁（`~/.cargo/bin/RSS-Reader/`），管理桌面版资料库时请用 `--data-dir` 或 `RSSR_DATA_DIR`。
- 内部：workspace 版本号改为跟随发布，Release 工作流在构建前检查 tag 与版本一致；CI 用时与算力优化；修复两处只在 macOS 本地出现的测试失败。

## 升级说明

- 本版没有资料库 schema 变化，阅读与界面行为与 v0.2.2 相同。升级前仍建议关闭旧程序并备份资料库。
- macOS：退出旧版后用新的 `RSS-Reader.app` 替换“应用程序”中的旧版。资料库在 `~/Library/Application Support/RSS-Reader/`，不在应用包内，替换不影响数据。若曾按 v0.2.2 说明手动去掉下载标记，新包无需再这样做。
