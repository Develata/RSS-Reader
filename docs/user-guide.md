# 使用指南

[30 秒开始阅读](../README.md#30-秒开始阅读)适合第一次打开应用；这里保留较细的订阅、阅读、配置交换和主题操作。界面命令与稳定选择器供主题或自动化开发者查看[前端命令参考](./design/frontend-command-reference.md)。

## 添加订阅与刷新

进入 **S**（Subscribe）页，输入 RSS / Atom feed URL 后按 Enter 或“添加订阅”。添加和首次刷新期间会显示进行中状态；重复提交不会再启动一轮。操作期间可以输入下一个地址，失败后可保留地址重试。

顶部 **R** 同时是 Read / Home：从订阅、设置、阅读页点击时只回全局文章页；已经位于全局文章页时再次点击才执行一次“刷新全部订阅”。刷新进行中重复点击会复用当前任务。手机文章首页滚到顶部后下拉，超过阈值才触发同一刷新；普通滚动和 Reader 正文选择不应触发它。单个订阅也可在订阅页单独刷新。

`v0.1.16` 已包含手动刷新成功提示约 1 秒后消失、窄侧栏搜索宽度修复和原生桌面右键菜单配置；Windows 系统菜单的实际弹出与选项仍待复验。详细验证边界见[本次交接记录](./handoffs/2026-09-23-home-search-context-menu.md)。

Web 直接请求远端 feed 会受 CORS 限制，桌面或 Android 能抓取的地址在普通静态 Web 版未必可用。需要在浏览器里验证受限源时，使用带登录的 [`rssr-web` / `/feed-proxy`](./deployment/web.md)。

## 查找与阅读

放大镜展开标题搜索框；Enter 进入搜索结果，Esc 收起。文章页支持来源、未读和收藏等筛选，并可按现有目录分组跳转。长来源名会换行显示完整名称，多页时紧凑分页控件保持在视口中，切页后回到新页阅读起点。

Reader 左上角是返回按钮。`M` 切换已读，`F` 切换收藏，`←` / `→` 跳转上一篇 / 下一篇未读；也可用页面上的上一篇 / 下一篇同订阅文章操作。图片可点击放大，关闭后回到原来的正文位置。标题、正文和合理的元数据使用浏览器 / WebView 原生文字选择与复制；带 Ctrl / Cmd 的复制、全选等组合键不由阅读快捷键拦截。

后台刷新可以更新本地数据，但不会把正在阅读的正文突然替换掉。正文只缓存 feed 本身提供的内容；不主动抓取原网站补全文。桌面和 Android 会在刷新后尽量本地化正文图片，Web 图片仍可能保留远端 URL。

## 设置、主题与配置交换

齿轮进入设置。可选内置主题，也能编辑、导入或导出自定义 CSS。想写自己的主题，先看[主题作者选择器参考](./design/theme-author-selector-reference.md)；主题只改变呈现，不负责刷新或导航逻辑。

配置交换支持 JSON 配置包、OPML 和 WebDAV 上传 / 下载。它用于迁移订阅和设置，不同步文章库、已读或收藏。CLI 对应命令见 `cargo run --locked -p rssr-cli -- --help`；刷新需明确指定 `refresh --all` 或 `refresh --feed-id <id>`，两者不能同时指定。`export-config`、`export-opml`、`show-settings` 的数据写入 stdout，诊断写入 stderr，可直接重定向到文件。

需要登录的 WebDAV 服务可在设置页 Endpoint 中填 `https://用户名:密码@dav.example.com/base/`。客户端会把凭据从请求 URL 中剥离，改用 HTTP Basic；Endpoint 只保存在当前设置会话，不进入本地配置包或导出的数据。用户名或密码含 `@`、`:` 等保留字符时，按 URL 规则百分号编码。避免在截图或共享屏幕时暴露当前输入框中的凭据。

## 数据备份

Linux `/usr/bin` 安装版的数据目录是 `$XDG_DATA_HOME/rss-reader/`，未设置该变量时为 `~/.local/share/rss-reader/`。Windows、macOS 和 Linux 便携版仍使用可执行文件同目录的 `RSS-Reader/`。索引库、正文库、界面偏好与 SQLite WAL 文件都应纳入本地备份；先正常退出应用，再复制整个数据目录。Web 的数据绑定当前浏览器存储与站点 origin，清除站点数据会删除本地阅读库。Android 卸载会清除应用沙箱内的数据库和缓存；导出配置只能保住订阅与设置，不能保住正文和阅读状态。

单独解压的 Linux CLI 仍按便携版规则从自身旁边找数据库；若要操作 `.deb` 桌面端的数据，请用全局 `--database-url` 明确指向上述数据目录里的 `rss-reader.db`，避免误以为两个不同目录中的库会自动合并。

`v0.1.17` Linux `.deb` 已声明实际动态库依赖，发布流水线在 Ubuntu 24.04 完成了普通用户安装后两次启动和数据复用检查。若 `v0.1.16` 或更早版本曾以管理员身份在 `/usr/bin/RSS-Reader/` 产生数据，新版不会自动读取或迁移它：退出应用后先备份，管理员再将完整目录复制到新位置并改为当前用户所有。普通便携版无需迁移，仍读取原位置。其它发行版安装前请核对包内 `Depends` 是否满足。

发布包和设备验收状态见[根 README](../README.md)与[Android 构建与验收状态](./roadmaps/android-release-roadmap.md)。
