`markers-object` 三种规模也已测量，数据见 JSON；它没有显示一致加速（5000 / 10000 组更慢，20000 组更快），不据此宣称所有输入都变快。Marker 拒绝后的输出改变是有意的整篇纯文本降级；其他这些夹具输出一致。内存没有显著下降，不把时间收益写成全面内存优化，也不把三次采样当统计显著性证明。

后台队列验证采用测试中可控的本地 HTTP 服务与内存 SQLite：前 5 个可下载候选均返回 403，第 6 个返回图片；首轮 5 次请求，第二轮能处理第 6 个，后续轮跳过其派生正文。额外的无图文章不占网络尝试额度。另有取消/陈旧结果/读写竞态与 10000 候选的准入测试。载荷界限是结构及字节计费断言，不是整个应用的峰值内存实测。

完整自动化结果、平台边界与独立复核结论以交接记录为准。未对 Android、macOS/Linux 原生界面、真实大订阅集合做本轮交互验收。

验证回执在执行后整理，记录原始本机日志的 SHA256、修改时间、执行命令及本次收尾时的源码 SHA256；源码清单不是测试启动时的签名证明。构建产物存于主仓库的 ignored target，但编译日志明确指向本工作树源码。原始日志留在本工作树 `target/parse-image-evidence/`，仓库内保存测试汇总和相关日志摘录；独立复核没有自行运行测试。
