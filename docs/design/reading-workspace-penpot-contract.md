## 1. 紧凑布局和宽度优先级

### 同日后续确认：保留现有阅读页和页面外侧留白

用户随后提供实际阅读页截图并明确：单篇文章阅读页目前的效果满意，暂时沿用实际代码版本，不重新设计其标题、正文排版、内容宽度和阅读工具栏。本文的“文章主面板＋目录”指文章列表工作区，不指单篇正文阅读页。

Home（文章列表首页）、Subscribe 及其他普通页面的左右页边距、居中容器与最大宽度也以现有实际代码版本为准，保留较宽的外围留白。双面板应在现有页面容器中布局；可用宽度不足时收起目录，而不是通过缩小全站左右页边距强行容纳两列。

12–16px 仅约束文章列表与目录之间的间距，以及前述面板内部的适度留白，不是全站页边距规范。之前“优先压缩外围留白”的表述不再用于缩小 Home、Subscribe 或阅读页的既有外侧留白。

下表为 v6 已落地、v7 保留的草模尺寸。v6 曾只读核对 `assets/styles/tokens.css`、`shell.css`、`responsive.css`：普通密度的页面容器最大宽度为 1080px；760px 窗口采用两侧各 16px。订阅草模原本已为 1080px 居中容器，继续保留。早期 v4 的 24px／12px 外围留白已被替换。

文章主面板与独立目录面板属于同一个阅读工作区。目录是辅助导航，两面板顶部对齐，不强行等高。保留当前暖色背景、配色与图标风格，不加重边框和阴影。

| 项目 | 桌面草模 | 窄窗口草模 |
| --- | --- | --- |
| 画板尺寸 | 1200 × 936 | 760 × 1000 |
| 横向外围留白 | 60px | 16px |
| 主面板宽度 | 868px | 728px，占满可用宽度 |
| 目录宽度 | 200px，右侧独立面板 | 默认收起；入口打开 200px 浮层 |
| 面板间距 | 12px | 无常驻第二列 |

宽窗口两面板间距尽量不超过 16px。仅压缩工作区内部重复内边距时，保留文字行距、按钮点击区域和正常标题换行。窄窗口第一篇使用两行长标题样例，不能通过强制单行截断来维持密度。

上表是两种预设画板，不是已经实现的响应式引擎或最终断点。实现时以文章可用宽度和长标题可读性决定收起时机；不要为了同时显示目录而把标题挤成过多行。

### v7：对齐与视觉层级

- 日期／来源分组、文章标题及来源日期副标题共用一条左对齐线：相对列表左侧 52px。通过 44px 选择区域加 8px 文字内边距形成，不缩小字体或选择点击范围。
- 分组文字使用独立的原生自动布局容器；同组相邻文章之间增加从标题起始位置延伸的极淡细线，不在分组前后堆叠整行边框。标题正常换行，既有行高保持。
- 未选择文章时，批量操作图标采用低强调的中性灰；选中后仍使用原强调色。行首默认选择框保持可见，悬停和选中规则沿用下文。
- 目录日期相对目录内容区缩进 24px，月份保持原层级；日期数量文字为 12px。来源分组目录不套用日期缩进。
- 以上更新覆盖 20 个文章画板；背景渐变、页面外侧留白、单篇阅读页、订阅页布局保持原约定。

## 2. 目录表示当前位置与跳转目标

- 日期继续用于定位文章，不变成日期筛选。点击日期不应把同页其他日期的文章从数据结果中移除。
- 文章列表保留轻量分组标识，便于确认定位结果。当前草模展示日期分组，条目副标题保留来源与日期；按来源分组沿用相同的标识层级。
- 用户在目录中滚动、展开或收起时进入独立浏览，允许收起当前位置的组、展开其他组，不能被自动拉回。
- 用户重新输入并使主文章列表实际滚动时，恢复自动跟随，仅展开当前位置需要的路径及祖先，收起无关组。
- 程序化定位、目录自身对齐、事件冒泡，以及已读／收藏元数据更新，不得冒充用户重新滚动主列表，也不得无故重置目录滚动位置和展开状态。
- 同页目录定位保持独立浏览状态；跨页等上下文变化仍按已有目录契约处理。鼠标和键盘遵循同一语义。

## 3. 滚动与多选

文章只有一个主要纵向滚动区域。目录过长时独立滚动，阅读工作区外层不再增加重复滚动容器。折叠目录、展开浮层只改变导航呈现，不改变筛选和文章集合。

| 操作 | 文章勾选规则 |
| --- | --- |
| 目录内部浏览、展开、收起 | 保留 |
| 收起整个目录、重新打开目录 | 保留 |
| 同页目录定位 | 保留 |
| 已读／收藏元数据变化 | 不因刷新而清空；目录独立浏览状态也保留 |
| 跨页，包括目录跳转到另一页 | 清空 |
| 应用来源／状态等筛选 | 清空 |
| 切换文章视图或分组上下文 | 清空 |
| 顶部全选 | 只作用于当前页文章，不扩大到其他页 |
| 批量已读、归档 | 只处理已选文章；未选时禁用 |

打开来源筛选弹窗和实际应用筛选是不同操作，打开弹窗本身不清空选择。归档后，已经移出当前列表的文章不继续残留在可操作的选择集合中。

### 轻量选择控件

- 行首方框统一为 16 × 16px、1px 暖灰描边、小圆角、未选时透明底色；外围仍保留 44 × 44px 点击区域。方形与右侧表示未读的圆圈保持区别。
- v8 默认描边为 `#cec4b8`，圆角 3.5px；经过整行时描边加深到 `#95816f`，不提前出现勾，也不加整行强调背景。进入 44px 勾选区域后，描边为 `#8e7a69`，区域使用 5.5% 暖灰浅底，并显示“选择文章”提示。
- 已有选中项时，其余方框使用 `#b6a99b` 略微增强。选中保持 `#b04a2f` 赭红白勾和 `#fff5ef` 淡暖行底色，行描边为空；顶部继续显示“已选 N”。
- 顶部未选全选框使用 `#aa9887`、1.2px 描边，比普通行略明显；悬停提示“选择当前页”，部分选择保留 10 × 2px 横线。点击选择区域只改变勾选，标题打开文章的产品语义不变。
- 键盘焦点与鼠标悬停分开展示：44px 区域有 2px 赭红焦点轮廓，空格切换选择。真实焦点顺序、键盘操作和辅助功能语义属于后续实现，本轮只画静态外观。
- 22 号对照画板扩为六种状态，并补充全选的未选／部分／全部状态。全部 22 个文章画板已同步基础样式，包括窄窗口、1920 × 1080 和 1536 × 864 画板。
- 桌面未选首条已有整行悬停、勾选区域悬停、提示、离开恢复和点击选择的示例连线；顶部全选已有提示及点击连线。其他行悬停和两张宽屏的交互仍为静态状态，不表示完整应用实现。

### 来源／时间 ToggleGroup

- 两项位于同一个 112 × 44px 的暖色分段底座中，单项 56 × 44px。v7 将底座调整为更浅的暖灰，选中项通过同色 2px 内描边形成浅色内片，保持完整点击区域及强调色文字，不保留两个各自描边的独立按钮外观。
- 单选且始终有一个活动项，表示文章的分组方式；与“全部来源／…”的来源集合筛选入口分开。
- 常用桌面时间分组状态可点击“来源”，进入按来源重排的 8 篇样例、6 个分组；点击“时间”回到未勾选时间状态。切换分组清空选择。
- 来源分组结果中的其他操作、窄窗口分组切换以及筛选／分组的任意组合尚未穷举连线。

### 同日后续确认：翻页固定在窗口底部并集中排列

用户明确：上一页／下一页的位置以实际代码版本为基准，始终在窗口底部；两个方向之间的距离要近，减少反复翻页时的鼠标移动。样式可以沿用草模中的细箭头、轻量页码和暖色，但不能把左右箭头拉到整块文章面板的两端。

## 4. 来源编辑与设置图标

文章页的“全部来源”只有筛选功能，不提供编辑来源入口。自定义名称和 RSS / Atom URL 的编辑位于订阅页条目右侧铅笔按钮；保存、取消都留在订阅页。

### 同日后续：来源筛选展开态与省略号摘要

- 全部来源选中时，收起的入口显示“全部来源”；只选部分来源时统一显示“…”并保留下拉箭头，包括只选一个来源的情况。入口保留原宽度，避免摘要变化推动相邻控件。
- 展开后完整显示来源名称、复选框、全选的选中／部分选中状态及已选数量。省略号只替代收起后的摘要，不隐藏下拉里的名称。
- v7 去掉已选来源的逐行大面积底色，用勾选标记表达选择；来源条目保留几乎透明的底面以维持整行命中区域。弹窗边线和正常来源入口边线适度减淡，应用按钮保持清楚。
- 暂时修改勾选属于草稿；关闭或点击外部不应用修改，不清空文章选择。点击“应用”后进入对应筛选结果并清空文章勾选。未选任何来源时“应用”不可用。
- v5 新增 `19 · 来源筛选展开 / 全部来源`、`20 · 来源筛选展开 / 部分来源（…）` 和 `21 · 来源筛选 / 展开对照` 三个原生可编辑静态画板；v6 已同步前两个整页画板的新布局并对齐弹窗位置。
- 原文章页来源入口接通“全部 → 未选 → 少数派 → 应用 → 省略号”的预设示例；再次打开保留少数派勾选，可恢复全选并应用。其他来源组合和搜索输入仍是静态外观，未模拟成完整筛选程序。
- v5 当时尚未重画的外围留白、底部紧凑分页和来源／时间 ToggleGroup，现已在 v6 统一更新。单篇阅读页继续沿用实际版本。

### 订阅来源编辑

## 5. 前端 Rust 与控件边界

- 两面板共享筛选、排序、分组和文章数据，不维护两份独立文章集合。
- 列表选择状态与目录展开／跟随状态分别管理；目录交互变化不触发整份文章重新查询、重新分组或无关投影重算。
- 状态转换和交互规则保留在前端 Rust。DOM 或未来原生控件负责测量、输入来源和实际滚动，向 Rust 交付必要的观测与意图。
- application / domain 的业务语义、host capability 与 adapter 边界沿用现状；本次不新增 crate，不重分业务职责，不因为视觉分块引入平台分叉。
- 面板分块、目录收起和静态草模本身不作为性能或内存优化成果；收益需另行实施并测量。

## 6. 草模中能点什么

所有页面由原生可编辑文字、矢量和组件组成。可在 Penpot 画布中拖动、调整尺寸和编辑文字；预览页中的字段点击只切换示例值。

| 场景 | 当前草模范围 |
| --- | --- |
| 未选 → 第一篇 → 第二篇 | 已连线，演示 0／1／2 篇选择 |
| 未选第一条的悬停／离开 | 已连线：经过整行加深方框，进入勾选区增加浅底和“选择文章”提示；离开恢复，键盘聚焦仍为静态外观 |
| 桌面来源／时间切换 | 已连线到 6 个来源分组的 8 篇样例，切换后未勾选 |
| 当前页全选和取消全选 | 已连线，示例为本页 8 篇；桌面未选全选框悬停提示“选择当前页” |
| 目录当前月折叠、旧月份展开 | 已连线，文章集合和已选 2 篇保持不变 |
| 同页 10 月 22 日／23 日定位 | 已连线到预设位置状态；保留全部日期分组及勾选，不执行真实滚动 |
| 桌面收起／恢复目录 | 已连线；保留已选 2 篇 |
| 窄窗口打开／关闭目录浮层 | 已连线；保留已选 2 篇 |
| 下一页／上一页 | 已连线，翻页后的选择为空 |
| 批量已读／归档 | 从桌面基准“已选 2 篇”连到结果，只改变或移除前两篇 |
| 来源筛选弹窗 | 全部／未选／少数派示例已接通应用及恢复全部；应用清空文章选择，部分来源摘要为“…” |
| 订阅来源编辑 | 少数派示例可切换名称、URL、两者同时修改并保存；取消、使用原名、错误状态沿用已有示例 |
| 其他来源的编辑 | 可查看表单布局和关闭，未为每一来源穷举所有字段状态 |

以下只记录规则或静态状态：真实滚动及自动跟随恢复、输入来源判别、自动响应式断点、其他来源组合／状态筛选、任意上下文组合的视图／分组切换、任意文章选择组合、真实自由输入与保存。批量操作只为桌面基准已选两篇接出结果；1 篇／8 篇和目录独立浏览／日期定位状态未穷举结果连线。来源分组结果页主要演示分组切换。上述限制不改变产品约定。
