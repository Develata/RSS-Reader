- 主导航、页面留白、1080px 内容容器、标题字体与实际工具栏尺寸。

## 预览边界

- 新版为状态快照，提供文章分组切换的三条示例连线；页面流程入口用于按分类查看画板。
- 未把自由输入、网络请求、持久化保存、真实滚动跟随或任意状态组合模拟为完整应用。
- 字体使用代码回退栈中的 `Noto Sans SC`。Penpot 字体 API 不支持 550 字重，文章标题映射为可用的 500，并在样式页注明；系统字体回退、原生表单控件和抗锯齿仍可能有细微差别。
- 画板按内容视口采集，浏览器滚动条属于宿主界面，不作为设计控件复制。不宣称跨平台逐像素相等。
- 原有 31 张旧预览仍在历史页，**不再作为当前视觉规格**；其历史连线与旧验收说明保持可查。
